ملف ZIP الأصلي غير محفوظ في المستودع. لا توجد رخصة مضافة لأن المستخدم لم يحدد رخصة.

## البناء والفحص

**تنبيه قابلية النقل:** `src/core/build.py` و`src/core/check_core.py` يحددان مجلد `final` بمسار ثابت هو `/home/user/CS2015/final`. لذلك تعمل الأوامر التالية كما هي فقط إذا كان جذر نسخة العمل في `/home/user/CS2015`؛ لم تُعدّل هذه المسارات أثناء الاستيراد.

```bash
cd /home/user/CS2015/src && python3 core/build.py m04
cd /home/user/CS2015/src && python3 core/check_core.py
cd /home/user/CS2015/src && python3 core/check_generators.py --runs 500
```

يفحص `build.py` تغطية الشرائح والمراجع الخارجية وبصمات الأساس. يحتاج فحص المولدات والأدوات الكامل إلى Node.js وPlaywright/Chromium. يمكن تشغيل فحص المولدات وحدها باستخدام `python3 core/check_generators.py --runs 500 --no-tools`. ملف إعداد Playwright المشار إليه في ملاحظات التطوير غير موجود في الحزمة المرفوعة.

## حالة التحقق كما وردت في مواد التسليم

النتائج التالية من سجل الحزمة وملاحظات التسليم، ولم تُعَد جميع الاختبارات من الصفر أثناء رفع الملفات:

- `check_core.py`: ‏101/101.
- `check_generators.py --runs 500`: ‏10,000 تشغيل للمولدات وخمسة فحوص للأدوات، دون إخفاق وفق تقرير التسليم.
- تحكمات المتصفح: M03 ‏53/53 وM04 ‏46/46؛ سجلاتها في `verification/`.
- بصمات ملفات HTML الأربعة تطابق `src/core/manifest.v1.1.json`.
- **ملاحظة حزمة:** مجلد `verification/shots_m04/` يحتوي 29 صورة PNG، بينما يذكر تقرير M04 وسجل التغيير 30 لقطة. اللقطة الناقصة غير محددة في الأرشيف؛ لا يُعد هذا المستودع دليلًا على اكتمال مجموعة الثلاثين.
- لم تُشغّل هنا حملة كاملة على Safari/Firefox/iOS، ولا توجد إعدادات CI في الحزمة.
