## 1) حركة حقيقية (Motion)

البنية: DOM دائم. تُرسم الجداول/الخانات/الشرائح/الخطوط **مرة واحدة** في `content.html`، والمحرّك يحرّك العناصر القائمة بالمعرّف عبر `transform/opacity` + Web Animations API. لا يوجد `innerHTML` لكل خطوة داخل المشهد (المتحوّل الوحيد هو نص التعليق/العداد/لوحة المتغيّرات).

*النموذج الحالي:* `goto(n)` لا يطبّق فروقًا تراكمية، بل **يعيد بناء الحالة**: عند القفز للأمام أكثر من خطوة، أو عند الرجوع، يصفّر الحالة ثم يعيد تطبيق الخطوات 0…n−1 بلا حركة، ويطبّق الخطوة n بحركة. النتيجة: القفز بالمِقبض أو زر Prev لا يترك أثرًا ناقصًا.

## 2) لا إيموجي ولا أيقونات-نص

- حزمة أيقونات واحدة `sprite.html` (24 `<symbol>`)، تُستهلك بـ `<use href="#i-…">`، `stroke:currentColor`, 1.75, `round` caps.
- استُبدلت كل العلامات النصية: `▶ ⏸ ◀ ↻ ✓ ✗ ✔ ○` → أيقونات SVG أو كلمات عربية («حرة» / «مشغولة» / «مكتمل») أو `free/taken` داخل خلايا التتبع الإنجليزية.
- **جرد العلامات غير النصية في النص الظاهر = 0** (الفحص آلي في `check_core.py`، ويسمح فقط بـ `→ ← · — … × %` داخل النثر).
- تحقق RTL: زر **التالي** يشير يسارًا (`i-next` = chevron-left) و**السابق** يشير يمينًا، وترتيب شريط التحكم يقرأ من اليمين: Start → السابق → التالي.

## 3) تسطيح التخطيط

- هيكل واحد فقط: `.shell` (شبكة rail + main) ← `.sec` ← محتوى مباشر. لا card داخل card، ولا جدول داخل بطاقة، ولا نشاط داخل صندوق.
- بديل البطاقات: مسافات (مقياس 8px)، خطوط شعرية `1px var(--hair)`، وعمود أرقام في الهامش (`.num` 2.4rem).
- **دعوة واحدة لكل شاشة**: `.aside` فقط (حدّ جانبي 2px)، وتظهر مرة واحدة في كل قسم تقريبًا؛ المواضع المستخدمة: `لماذا هذا المثال؟` / `ملاحظة على الشريحة` / `إضافي (خارج الشرائح)`.
- الجداول: بلا تخطيط متبادل، رأس لاصق، خطوط أفقية فقط، تمرير أفقي عند الحاجة.
- الكود: عالي التلوين صغير مدمج (تعليق/نص/رقم/كلمة مفتاحية)، أرقام أسطر، نسخ **أيقونة فقط** مع حالة «تم النسخ» (execCommand fallback).
- الألوان: `--accent` للتفاعل والحالة النشطة فقط؛ أخضر/أحمر/كهرماني للتحقق والتغذية الراجعة فقط. تم فحص الوضعين الفاتح والداكن بشكل منفصل.
